# SplitEase-Mobile-App

SplitEase is a Flutter mobile application designed to simplify expense splitting and help groups calculate individual contributions based on shared and personal expenses.

## Features

- Manage participants
- Track individual expenses
- Configure taxes and additional charges
- Split shared expenses equally
- Calculate individual contributions
- View expense breakdowns
- Reset expense calculations

## Tech Stack

- Flutter
- Dart

## Purpose

SplitEase is a personal learning project developed as part of a software development and QA Automation portfolio.
